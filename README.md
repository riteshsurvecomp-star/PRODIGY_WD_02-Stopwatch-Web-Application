

# PRODIGY_WD_02 — Stopwatch Web Application

This repository contains my submission for Task 02 of the Web Development Internship at **Prodigy InfoTech**.
The project is a modern and interactive stopwatch web application built using core web technologies.

---



## 🧭 About

This project is a functional stopwatch that allows users to:

✔ Start the timer

✔ Pause / Stop the timer

✔ Reset the time

✔ See elapsed time in minutes : seconds : milliseconds format

It demonstrates basic DOM manipulation and time-based JavaScript logic to create a responsive and user-friendly stopwatch.

## ✨ Key Features

⏱ Start / Stop functionality

⏸ Pause and resume timing

🔄 Reset stopwatch

🕒 Display in minutes, seconds and milliseconds



## 🛠️ Tech Stack

HTML — Structure

CSS — Styling and layout

JavaScript — Stopwatch logic and interactivity
